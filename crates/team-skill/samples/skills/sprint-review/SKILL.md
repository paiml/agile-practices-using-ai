# Sprint review

1. List the stories planned for this sprint.
2. For each story, run its acceptance tests. A story is Done only if they pass
   and it is merged.
3. Write two lists: Done, and Not Done with one line on why.
4. Do not move a Not Done story into Done. Carry it to the backlog instead.
